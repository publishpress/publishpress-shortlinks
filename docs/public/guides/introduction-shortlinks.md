# Introduction to PublishPress Shortlinks

With [PublishPress Shortlinks](https://publishpress.com/links/shortlinks) you can create custom links for your posts. These links are brandable, trackable, and can have custom view permissions. You can share links for any type of content, even unpublished posts in draft status.

[PublishPress Shortlinks](https://publishpress.com/links/shortlinks) will automatically generate links for all your posts and pages. This makes it really easy to have shareable links for content. These shortlinks are available from the Posts screen as in this screenshot below:

![Shortlinks on Post screen](https://docs-media.publishpress.com/publishpress-shortlinks/shortlinks-posts-screen-3e0320d0ee.webp)

These links will also be available via the Post Edit screen, as in this screenshot below:

![Shortlinks on Post Edit screen](https://docs-media.publishpress.com/publishpress-shortlinks/shortlinks-edit-screen-1761b9f3df.webp)
