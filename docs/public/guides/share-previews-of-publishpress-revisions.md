# Share Previews of PublishPress Revisions (Pro)

This feature requires the Pro version of the PublishPress Shortlinks plugin.

The [PublishPress Shortlinks](https://publishpress.com/links/shortlinks) plugin allows to create shareable links for revisions created with the [PublishPress Revisions](https://publishpress.com/links/revisions) plugin. This allows to share preview of unpublished changes to your content.

To start this process, create a revision of a published post on your website. In the the screenshot below, this can be done with the “Create Revision” link.

![Create Revision link](https://docs-media.publishpress.com/publishpress-shortlinks/create-revision-10ad269fc3.webp)

When you submit the revision, [PublishPress Shortlinks](https://publishpress.com/links/shortlinks) will automatically create a shareable link for your revision. You can see this in the screenshot below. The shortlink marked as “Internal” is the original post. The shortlink marked as “Revision” is the unpublished revision of that post.

![Shortlinks revisions and internal](https://docs-media.publishpress.com/publishpress-shortlinks/revision-labels-shortlinks-a093b0062d.webp)

This feature can be configured by going to Shortlinks > Settings > Revisions.

![Revisions settings](https://docs-media.publishpress.com/publishpress-shortlinks/shortlinks-settings-revisions-16a14dadf3.webp)
