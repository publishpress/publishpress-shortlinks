# Automatically Add Links to Keywords

The [PublishPress Shortlinks](https://publishpress.com/links/shortlinks) plugin allows you to automatically add links to keywords in your content. To see how this feature works, we’ll use the example of an “About WordPress” post that you can see in the screenshot below.

![Add links to keywords](https://docs-media.publishpress.com/publishpress-shortlinks/links-keywords-2c8fad8354.webp)

First, create a Shortlink and add the URL that you want to use for the automatic links. In the screenshot below, we’re linking to the official WordPress website.

![Add new shortlink](https://docs-media.publishpress.com/publishpress-shortlinks/wordpress-official-shortlink-f5092fe366.webp)

Under the “Auto-linking” tab, enter the keywords that you want to add this link to. We’re going to automatically add our new shortlink every time the word “WordPress” appears in a post.

![Auto-link keyword](https://docs-media.publishpress.com/publishpress-shortlinks/auto-linking-tab-90a6e98781.webp)

Now go back to your original post and you’ll see that the word “WordPress” is automatically linked to the Shortlink you created.

![About WordPress post with shortlinks](https://docs-media.publishpress.com/publishpress-shortlinks/added-links-d00e7806b2.webp)
